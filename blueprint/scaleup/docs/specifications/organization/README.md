# Organization Specifications

Organization specifications cover the creation, administration, and governance of an Organization — the entity a subscribed user creates to unlock the Organization Workspace.

| Document | Purpose |
| :--- | :--- |

| [ORGANIZATION_PROFILE.md](./ORGANIZATION_PROFILE.md) | The public-facing identity of an organization within the Community |

---

## Design Constraint

Specifications here govern **who can access the workspace and how it is administered** — not the operational tools used once inside it. Operational and financial capabilities belong in [specifications/business](../business/), and the commercial model belongs in [specifications/subscription](../subscription/).

See [BUSINESS_MODEL.md](../../BUSINESS_MODEL.md) for the subscription rationale and [ADR-002](../../decisions/ADR-002-subscription-model.md) for the underlying decision.
