# Organization Specifications

Organization specifications cover the creation, administration, and governance of an Organization — the entity a subscribed user creates to unlock the Business Workspace.

## Scope

- **Organization Creation** — the process by which an Individual establishes an Organization.
- **Subscription Management** — activating, maintaining, and managing the subscription that unlocks the workspace.
- **Team Management** — inviting and managing members within an Organization.
- **Organization Settings** — configuration and administration of an Organization's presence and preferences.

## Design Constraint

Specifications here govern **who can access the workspace and how it is administered** — not the operational tools used once inside it. Operational and financial capabilities belong in [specifications/business](../business/).

See [BUSINESS_MODEL.md](../../BUSINESS_MODEL.md) for the subscription rationale and [ADR-002](../../decisions/ADR-002-subscription-model.md) for the underlying decision.
