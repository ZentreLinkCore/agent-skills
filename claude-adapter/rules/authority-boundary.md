# Authority Boundary

Each `/webkit-*` skill owns ONLY its assigned responsibility. Do NOT perform responsibilities belonging to another skill. If a task belongs to another workflow stage: **stop, report the issue** (`Authority boundary: <the task> belongs to /webkit-<skill>. Not done here.`), **and do not continue** that task. Do not compensate for another skill. Do not generate work outside your authority.

> The full rule, with the table of which skill owns what, is **`.agents/rules/authority-boundary.md`** — read it when deciding where a task belongs.
