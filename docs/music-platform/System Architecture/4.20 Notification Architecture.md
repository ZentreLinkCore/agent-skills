## 4.20 Notification Architecture

Notifications shall have both persistent and realtime components.

```text
Application Event
       │
       ├───────────────┐
       ▼               ▼
Database            Realtime
       │               │
Persistent          Immediate
Notification        Notification
       │               │
       └───────┬───────┘
               ▼
          Client Interface
```

For example, when a user receives a message:

```text
MessageSent
    │
    ├── Save Message
    │
    ├── Create Notification
    │
    └── Broadcast Realtime Event
```

If the recipient is offline, the persistent notification can remain available when the user returns.
