## 4.32 Recommended Initial Technology Stack

The initial implementation shall use the following architecture:

| Layer                            | Technology                   |
| -------------------------------- | ---------------------------- |
| Web Frontend                     | React                        |
| Language                         | TypeScript                   |
| Build Tool                       | Vite                         |
| Backend                          | Laravel                      |
| Backend Language                 | PHP                          |
| Authentication                   | Laravel Sanctum              |
| Database                         | PostgreSQL                   |
| Cache                            | Redis                        |
| Queue                            | Laravel Queue + Redis        |
| Realtime                         | Pusher                       |
| Development Realtime Alternative | Laravel Reverb               |
| Realtime Client                  | Laravel Echo + Pusher JS     |
| File Storage                     | S3-compatible/Object Storage |
| Search                           | PostgreSQL initially         |
| Music                            | Provider abstraction         |
| Desktop                          | Tauri + React                |
| Mobile                           | React Native                 |
| API Style                        | Versioned REST API           |
| Architecture                     | Modular / API-first          |
