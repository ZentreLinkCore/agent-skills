## 4.27 Deployment Architecture

The initial deployment may use a simplified architecture suitable for the project's early stage.

```text
                    Internet
                       │
                       ▼
                  HTTPS / TLS
                       │
                ┌──────▼──────┐
                │ Web Hosting │
                │             │
                │ Laravel API │
                │ React Build │
                └──────┬──────┘
                       │
             ┌─────────┼──────────┐
             ▼         ▼          ▼
        PostgreSQL   Redis      Pusher
                                  │
                           WebSocket Clients
```

For the initial shared-hosting environment, Pusher shall reduce the need to operate a persistent WebSocket server directly on the hosting account.

As the system grows, the architecture may be migrated to:

```text
                    Load Balancer
                          │
             ┌────────────┼────────────┐
             ▼            ▼            ▼
        Laravel App   Laravel App   Laravel App
             │            │            │
             └────────────┼────────────┘
                          │
                    PostgreSQL
                          │
                        Redis
                          │
                    Realtime Layer
```

The deployment architecture shall therefore remain flexible enough to support future infrastructure growth.
