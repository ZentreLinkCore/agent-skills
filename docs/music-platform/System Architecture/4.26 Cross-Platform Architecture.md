## 4.26 Cross-Platform Architecture

The backend shall be shared across all client platforms.

```text
                    Laravel API
                        │
          ┌─────────────┼─────────────┐
          │             │             │
          ▼             ▼             ▼
      React Web    React Native    Tauri Desktop
```

Each client may have platform-specific UI and interaction behavior while using the same:

* Authentication
* API
* Business rules
* Database
* Realtime events
* Music integration
* Jam service

This approach reduces duplicated backend logic.
