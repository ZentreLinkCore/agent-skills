## 4.17 Jam Architecture

The Jam module shall act as the coordination layer between users and the music playback system.

A Jam shall contain:

* Jam ID
* Host
* Participants
* Privacy mode
* Current track
* Playback status
* Playback position
* State version or identifier
* Server timestamp
* Created time
* Updated time
* Ended state

### Jam Architecture

```text
                    ┌───────────────────┐
                    │   Music Provider  │
                    └─────────▲─────────┘
                              │
                         Audio Playback
                              │
                       ┌──────┴──────┐
                       │ Client Apps  │
                       └──────▲──────┘
                              │
                       Playback State
                              │
                    ┌─────────┴─────────┐
                    │    Jam Service    │
                    └─────────┬─────────┘
                              │
                        Jam Events
                              │
                       ┌──────▼──────┐
                       │   Pusher    │
                       └──────┬──────┘
                              │
                    ┌─────────┼─────────┐
                    ▼         ▼         ▼
                 User A    User B    User C
```

The Jam service shall coordinate playback state but shall not be responsible for transmitting the actual music audio.
