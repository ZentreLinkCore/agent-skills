## 4.21 Background Processing Architecture

Long-running or non-critical operations shall be processed asynchronously where appropriate.

Examples include:

* Email delivery
* Push notification delivery
* Media processing
* Search indexing
* Cleanup operations
* Audit processing
* Provider metadata synchronization
* Notification maintenance

The architecture shall separate realtime operations from background jobs.

```text
HTTP Request
     │
     ├── Critical Operation → Immediate Response
     │
     └── Background Work → Queue
                              │
                              ▼
                         Queue Worker
                              │
                              ▼
                         Job Processor
```

Realtime Jam playback shall not depend on slow background jobs.
