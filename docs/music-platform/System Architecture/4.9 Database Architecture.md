## 4.9 Database Architecture

PostgreSQL shall serve as the primary relational database.

The database shall contain persistent application data including:

```text
Users
Profiles
Settings
Conversations
Conversation Members
Messages
Message Reactions
Message Mentions
Message Reads
Attachments
Groups
Communities
Community Members
Channels
Notifications
Jams
Jam Members
Jam Playback States
Music Metadata
Audit Logs
```

The database shall maintain relationships and constraints necessary to preserve data integrity.

### Database Principle

```text
PostgreSQL
     │
     ├── Source of Truth
     │
     ├── Persistent Records
     │
     ├── Relationships
     │
     └── Transactional Operations
```

Realtime providers, caches, and client state shall not replace PostgreSQL as the authoritative source for persistent application data.
