## 4.13 Messaging Architecture

Messaging shall use a combination of persistent API operations and realtime events.

### Message Flow

```text
User A
  │
  │ Send Message
  ▼
React Client
  │
  │ POST /messages
  ▼
Laravel API
  │
  ├── Authenticate
  ├── Authorize
  ├── Validate
  ├── Store Message
  └── Commit Transaction
          │
          ▼
      MessageSent
          │
          ▼
        Pusher
          │
      ┌───┴────┐
      ▼        ▼
   User B    User C
```

The database shall contain the authoritative message record.

Realtime delivery shall notify connected clients that a message has been created or updated.
