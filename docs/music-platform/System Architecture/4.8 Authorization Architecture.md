## 4.8 Authorization Architecture

Authorization shall be enforced on the backend.

The system shall use resource-based authorization rather than relying exclusively on global user roles.

For example:

```text
User A
 ├── Community X → Owner
 ├── Community Y → Member
 └── Jam Z → Host
```

The same user may therefore have different permissions depending on the resource being accessed.

Authorization shall be applied to:

* Conversations
* Messages
* Groups
* Communities
* Channels
* Files
* Jams
* Administrative resources

Frontend visibility shall not be considered a security mechanism.
