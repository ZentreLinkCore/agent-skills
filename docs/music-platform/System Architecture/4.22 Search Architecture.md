## 4.22 Search Architecture

Search shall be separated into application search and external music-provider search.

### Application Search

Application search may include:

```text
Users
Messages
Conversations
Groups
Communities
Channels
Jams
```

Potential search technologies include:

* PostgreSQL full-text search
* Meilisearch
* Elasticsearch
* OpenSearch

The initial implementation may begin with PostgreSQL-based search and evolve if scale requires a dedicated search engine.

### Music Search

Music searches shall be delegated to the configured music provider through the music integration layer.

```text
Search Request
      │
      ├───────────────┐
      ▼               ▼
Application Search   Music Provider
      │               │
      └───────┬───────┘
              ▼
        Unified Results
```

Search results shall still respect authorization, privacy, and provider restrictions.
