## 4.19 File and Object Storage Architecture

Uploaded files shall be stored separately from relational database records.

The database shall store metadata such as:

```text
Attachment ID
Message ID
Original Filename
Storage Key
MIME Type
File Size
Uploaded By
Created At
```

The actual binary file shall be stored in an appropriate storage system.

Possible storage implementations include:

* Local storage during development
* Object storage
* S3-compatible storage
* Cloud storage provider

The application shall use an abstraction layer so the storage provider can be changed without rewriting the messaging system.
