## 4.5 Application Layer

The application layer coordinates use cases between controllers, domain services, repositories, models, integrations, and other application components.

A request shall generally follow this flow:

```text
HTTP Request
     │
     ▼
Controller
     │
     ▼
Form Request / Validation
     │
     ▼
Application / Domain Service
     │
     ├───────────────┐
     ▼               ▼
Repository       External Service
     │               │
     ▼               ▼
Database         Provider API
     │
     ▼
Domain Event
     │
     ▼
Realtime / Notification / Queue
```

Controllers should remain thin and should not contain large amounts of business logic.

For example, a message-sending operation should conceptually follow:

```text
MessageController
       │
       ▼
SendMessageService
       │
       ├── Validate permissions
       ├── Validate conversation
       ├── Create message
       ├── Store attachments
       ├── Create mentions
       ├── Commit transaction
       └── Dispatch MessageSent
                    │
                    ▼
                  Pusher
```
