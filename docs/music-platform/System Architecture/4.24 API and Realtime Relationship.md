## 4.24 API and Realtime Relationship

The API and realtime layers shall have separate responsibilities.

### API

Responsible for:

* Creating data
* Updating data
* Deleting data
* Authentication
* Authorization
* Validation
* Business rules
* Persistent state

### Realtime

Responsible for:

* Informing connected clients
* Delivering state changes
* Typing indicators
* Presence
* Notifications
* Jam synchronization events

The general principle shall be:

```text
API = Command + Persistent State

Realtime = Event Distribution
```

For example:

```text
POST /messages
      │
      ▼
Create Message
      │
      ▼
PostgreSQL
      │
      ▼
MessageSent
      │
      ▼
Pusher
      │
      ▼
Connected Clients
```
