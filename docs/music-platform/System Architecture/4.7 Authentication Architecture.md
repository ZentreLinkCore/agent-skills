## 4.7 Authentication Architecture

Authentication shall be handled by the Laravel backend.

The system shall authenticate users before granting access to protected resources.

A typical flow shall be:

```text
User
 │
 │ Login
 ▼
React Client
 │
 │ POST /api/v1/auth/login
 ▼
Laravel API
 │
 ├── Validate credentials
 ├── Authenticate user
 └── Create authenticated session/token
 │
 ▼
Authenticated Client
```

The authentication mechanism shall be selected based on the deployment and client requirements, with Laravel Sanctum as the initial candidate.

Authentication shall be separate from authorization.

Authentication answers:

> Who is the user?

Authorization answers:

> What is this user allowed to do?
