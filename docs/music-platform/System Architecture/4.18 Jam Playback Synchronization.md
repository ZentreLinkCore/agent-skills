## 4.18 Jam Playback Synchronization

A Jam playback event may contain information similar to:

```json
{
  "event": "jam.play",
  "track_id": "track-123",
  "position": 42.35,
  "server_timestamp": 1790000000000,
  "state_version": 18
}
```

The receiving client shall calculate the appropriate playback position based on the event timestamp, local timing, and current network conditions.

For example:

```text
Received Position = 42.35 seconds

Network delay = 0.25 seconds

Estimated Current Position
= 42.35 + 0.25
= 42.60 seconds
```

The actual synchronization algorithm shall be refined during implementation and testing.

The system should avoid forcing continuous server updates for playback position.

Instead:

```text
PLAY
  ↓
Broadcast initial state
  ↓
Clients calculate playback locally
  ↓
Periodic synchronization
  ↓
Correct significant drift
```
