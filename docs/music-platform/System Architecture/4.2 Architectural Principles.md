## 4.2 Architectural Principles

The system architecture shall follow the following principles.

### 4.2.1 API-First Architecture

The backend shall expose functionality through versioned APIs instead of implementing business logic exclusively inside the web client.

The initial API namespace shall use:

```text
/api/v1
```

This allows future applications to consume the same backend.

For example:

```text
Web Application
       │
       ├──────────────┐
       │              │
Mobile Application  Desktop Application
       │              │
       └───────┬──────┘
               │
          Laravel API
```

The backend shall therefore remain independent of the presentation technology.
