## 4.23 Caching Architecture

Caching shall be used to improve performance without compromising data consistency.

Potential cache targets include:

* Public profile information
* Community information
* Channel information
* Search results
* Music metadata where permitted
* Application configuration
* Feature flags

Example cache keys:

```text
user:profile:{userId}
community:{communityId}
channel:{channelId}
music:search:{queryHash}
```

Cache invalidation shall occur when the underlying data changes.

User-specific and permission-sensitive data shall be handled carefully to prevent accidental exposure between users.
