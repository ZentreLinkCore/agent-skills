## 4.30 Architectural Source-of-Truth Rules

The system shall establish clear ownership of data.

| Data                         | Primary Source of Truth |
| ---------------------------- | ----------------------- |
| User Account                 | PostgreSQL              |
| User Profile                 | PostgreSQL              |
| Messages                     | PostgreSQL              |
| Reactions                    | PostgreSQL              |
| Community Membership         | PostgreSQL              |
| Channel Membership           | PostgreSQL              |
| Notifications                | PostgreSQL              |
| Jam Membership               | PostgreSQL              |
| Current Persistent Jam State | PostgreSQL              |
| Music Provider Catalog       | External Music Provider |
| Uploaded File Binary         | Object/File Storage     |
| Cache                        | Redis                   |
| Queue State                  | Queue/Redis             |
| Realtime Event               | Realtime Provider       |
| Local Playback Position      | Client                  |
| UI State                     | Client                  |

This separation is important because temporary systems such as caches and realtime connections may disappear without representing permanent data loss.
